# Python CLI Calculator

A modular, Command-Line Interface (CLI) calculator built with Python applying Object-Oriented Programming (OOP) principles, exception handling, and local file history logging[cite: 1].

## Features
- **Core Operations:** Supports addition, subtraction, multiplication, and division[cite: 1].
- **Error Prevention:** Robust exception handling for invalid string inputs and divide-by-zero errors[cite: 1].
- **Data Persistence:** Automatically appends calculation history to a local file (`history.txt`)[cite: 1].

## Concepts Covered
- Object-Oriented Programming (Classes & Methods)[cite: 1]
- File Handling (`r` and `a` modes)[cite: 1]
- Exception Handling (`try-except` blocks)[cite: 1]
- User Input Validation[cite: 1]
